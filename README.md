# Рядом — анонимный чат с психологом

Веб-платформа для детей, столкнувшихся с травлей. Ребёнок открывает сайт и сразу
оказывается в разговоре: без регистрации, без имени, без анкеты.

- **Фронтенд:** Vue 3 + TypeScript + Vite
- **Бэкенд:** NestJS + TypeScript, Socket.IO, Prisma
- **База:** PostgreSQL 16
- **Развёртывание:** Docker Compose, за nginx

---

## 1. Что нужно установить на Windows 11

| Инструмент | Зачем | Проверка |
|---|---|---|
| [Docker Desktop](https://www.docker.com/products/docker-desktop/) с WSL 2 | контейнеры | `docker --version` |
| [Node.js 20 LTS](https://nodejs.org/) | режим разработки | `node -v` |
| [Git](https://git-scm.com/download/win) | код | `git --version` |

После установки Docker Desktop перезагрузите компьютер и убедитесь, что кит в
трее зелёный — иначе `docker compose` не ответит.

## 2. Быстрый запуск: всё в Docker

Открой PowerShell в папке проекта.

```powershell
# 1. Создать файл переменных окружения
Copy-Item .env.example .env

# 2. Открыть .env и заменить пароли на свои
notepad .env

# 3. Собрать и поднять три контейнера: база, API, веб
docker compose up --build
```

Первая сборка занимает 3–6 минут. Когда в логах появится `API слушает порт 3000`:

- **Экран ребёнка** — http://localhost:8080
- **Панель психолога** — http://localhost:8080/psy
  (логин и пароль из `OPERATOR_LOGIN` / `OPERATOR_PASSWORD` в `.env`)

Проверка связки: открой два окна браузера — обычное на `/` и приватное на `/psy`.
Напиши что-нибудь из детского окна, диалог появится в очереди психолога.

Остановить: `Ctrl + C`, затем `docker compose down`.
Удалить вместе с базой: `docker compose down -v`.

## 3. Режим разработки с горячей перезагрузкой

В Docker остаётся только база, фронтенд и бэкенд запускаются локально — так Vite
мгновенно обновляет стили.

**Терминал 1 — база:**
```powershell
docker compose up db
```

**Терминал 2 — бэкенд:**
```powershell
cd backend
npm install
Copy-Item ..\.env .env
npx prisma generate
npx prisma migrate deploy
npm run start:dev
```

В `backend\.env` строка подключения должна указывать на `localhost`, а не на `db`:
```
DATABASE_URL=postgresql://ryadom:change-me-local@localhost:5432/ryadom?schema=public
```

**Терминал 3 — фронтенд:**
```powershell
cd frontend
npm install
npm run dev
```

Открыть http://localhost:5173. Vite сам проксирует `/api` и WebSocket на порт 3000.

Полезное:
- `npm run typecheck` в `frontend` — проверка типов Vue-компонентов
- `npx prisma studio` в `backend` — просмотр базы в браузере

## 4. Что уже работает

**Экран ребёнка**
- Вход сразу в чат, приветствие психолога уже написано
- Готовые фразы для тех, кому трудно начать
- Кнопка «Быстро закрыть» и тройное нажатие `Esc` — мгновенный уход на нейтральный сайт
- Переписка по умолчанию живёт только до закрытия вкладки; постоянное хранение включается вручную
- Кнопка «Удалить переписку» стирает диалог и на сервере
- Автоматическое переподключение при обрыве связи, сообщения не теряются
- Телефоны 112 и 8 800 2000 122 видны всегда

**Скрининг риска**
`backend/src/safety/safety.service.ts` проверяет каждое сообщение по списку
маркеров. При критическом совпадении диалог поднимается в начало очереди,
психологу летит `operator:alert`, а ребёнок сразу видит записку с телефонами —
не дожидаясь, пока освободится специалист. Списки маркеров нужно пополнять
вместе с методистом.

**Панель психолога** (`/psy`) — рабочая, но намеренно минимальная: очередь с
приоритетом по риску, история диалога, ответ. Это следующая область для развития.

## 5. Приватность в архитектуре

- Ребёнок не вводит ни имени, ни телефона, ни почты. Форм регистрации нет
- Связь браузера с диалогом — случайный 256-битный токен; на сервере хранится
  только его `sha256`, поэтому по базе нельзя восстановить токен и войти в чужой диалог
- Психолог видит только псевдоним вида «Гость-4821»
- IP-адреса не пишутся в базу; в nginx стоит `X-Robots-Tag: noindex`
- `location.replace` при быстром выходе не оставляет страницу в кнопке «Назад».
  Полностью очистить историю браузера из JavaScript нельзя — об этом честно
  сказано в блоке «Приватность» в интерфейсе

## 6. Перед публикацией на антибуллинг.рф

Технические шаги:

1. Купить домен и направить A-запись на сервер
2. Домен кириллический, в конфигах нужен punycode:
   `xn--80aaaggjbgcqcbfhbbi0a5c.xn--p1ai`
3. Поставить перед контейнерами Caddy или nginx с Let's Encrypt, включить HSTS
4. В `.env` продакшена: новый `JWT_SECRET` (`openssl rand -hex 32`), стойкий пароль
   базы, `CORS_ORIGINS` с обоими написаниями домена
5. Шрифты Onest и Golos Text сейчас грузятся с Google Fonts — для продакшена
   положить `.woff2` в `frontend/public/fonts` и раздавать со своего домена
   (быстрее и не утекает IP посетителей)
6. Настроить бэкапы тома `db-data` и ротацию: диалоги старше N месяцев удалять
7. Добавить мониторинг доступности `/api/health`

Организационные — без них продукт запускать нельзя:

1. Проверка дипломов психологов и договоры с ними; в чате работают только
   подтверждённые специалисты
2. Письменный протокол эскалации: что делает специалист при угрозе жизни,
   насилии в семье, признаках преступления против ребёнка
3. Политика конфиденциальности и пользовательское соглашение с учётом 152-ФЗ
   и требований к информации для детей
4. Супервизия специалистов и разбор сложных случаев
5. Правило, зашитое и в текстах интерфейса: сервис не заменяет взрослого рядом,
   а помогает ребёнку найти и подключить того, кому можно доверять

## 8. Если что-то не запускается

| Симптом | Причина и решение |
|---|---|
| `docker: error during connect` | Docker Desktop не запущен |
| `port is already allocated` | занят 8080, 3000 или 5432 — поменяй левое число в `ports` |
| Белый экран, в консоли ошибки WebSocket | бэкенд не поднялся, смотри `docker compose logs backend` |
| `Can't reach database server` | база ещё стартует, подожди 10 секунд; или пароль в `.env` не совпал с томом — `docker compose down -v` |
| Кириллица в PowerShell ломается | `chcp 65001` перед запуском |
| Prisma не скачивает движки при сборке | нет доступа к `binaries.prisma.sh` — проверь прокси или VPN |
